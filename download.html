Install

  1. Download the APK on the Android phone.
  2. Open the downloaded file.
  3. If requested, allow this browser to install unknown apps.
  4. Choose Install, then open Viora.

Google Play purchases may not work in this temporary build. Use the Google Play version for purchase testing.

Instruções em português

  1. Baixe o APK no celular Android.
  2. Abra o arquivo baixado.
  3. Se solicitado, permita que o navegador instale apps desconhecidos.
  4. Toque em Instalar e depois abra o Viora.
